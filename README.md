# Network Metrics Monitoring & Visualization Demo

A state-of-the-art demo project to collect, analyze, and visualize network performance metrics like latency, throughput, and packet loss using tools like iperf3, Prometheus, and Grafana.

## Structure
- `scripts/` – Python scripts for data collection and exporting metrics
- `data/` – Raw data files (CSV)
- `notebooks/` – Jupyter Notebooks for analysis & visualization
- `docker-compose.yml` – Setup for Prometheus & Grafana
